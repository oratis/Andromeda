# Andromeda 专题研究

本目录收录支撑 Andromeda 产品与架构决策的专题研究。

基础全景：

- [PC 与 macOS 操作系统全景及 Andromeda 架构建议](../os-landscape-and-andromeda-architecture.md)

研究标准：

- 优先采用项目官方文档、源代码仓库、标准组织与厂商资料；
- 区分“开源可用”“技术上可行”“许可证允许”和“达到消费级产品质量”；
- 对关键项目记录许可证、成熟度、复用方式与已知缺口；
- 兼容性结论必须落实为版本化测试，不能仅依据项目宣传；
- “覆盖所有项目”按相关技术类别与代表性项目处理，不声称枚举互联网上每个实验性仓库；
- 涉及许可证的结论用于风险识别，不构成法律意见。
- 调研文档记录检索日期；进入 Adopt/Pilot 或发布镜像时必须把项目 release/tag/commit、构建选项、内容哈希与逐文件许可证锁定到 SBOM，不能把本页的动态上游状态当成可复现构建输入。
